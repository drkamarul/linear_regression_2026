# Linear Regression 2026

Teaching materials for linear regression in the DrPH programme, School of Medical Sciences, Universiti Sains Malaysia.

**Author:** Kamarul Imran Musa

**Site:** https://drkamarul.github.io/linear_regression_2026/

- [Lecture](https://drkamarul.github.io/linear_regression_2026/chapter/linear_regression_health_medicine.html) — *Linear Regression Analysis in Health and Medicine*
- [Practical](https://drkamarul.github.io/linear_regression_2026/practical/mssm_linear_regression_practical.html) — REAAAPP workflow in R

## Clone

```bash
git clone https://github.com/drkamarul/linear_regression_2026.git
```

The `.qmd` source files are in `chapter/` and `practical/`. To re-render them you need R, Quarto, the packages listed in those documents, and the data file (see below).

## Data

The MSSM fasting blood sugar Excel file is **not** in this repository. It is provided in class or via eLearn. Place it at:

```
dataset/mssm_fasting_blood_sugar.xlsx
```

relative to the repository root (the same layout used in the lecture and practical documents).
