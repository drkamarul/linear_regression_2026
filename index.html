Linear Regression in Health and Medicine

Kamarul Imran Musa School of Medical Sciences, Universiti Sains Malaysia

Course materials for the DrPH programme and other postgraduate students in public health and epidemiology. The lecture note develops the method; the practical shows the R code that carries it out. Both are built on the same MSSM fasting blood sugar dataset and report the same models.

Lecture Note

Linear Regression Analysis in Health and Medicine

The chapter. Covers simple and multiple linear regression, the LINE conditions, dummy variables and categorical covariates, confounding, interaction, transformation and multicollinearity, model comparison, and residual diagnostics. Code is hidden so the argument stays in view.

Teaching materials. These documents are prepared for teaching. The analyses use data from the Metabolic Syndrome Study in Malaysia (MSSM) and are presented to illustrate method, not to report study findings; they must not be cited as results. The .qmd source files are provided for reading and reference. The dataset is not distributed with them — students receive the file in class or via eLearn and place it at dataset/mssm_fasting_blood_sugar.xlsx before re-rendering.
